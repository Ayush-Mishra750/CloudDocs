# CloudDocs — Resume Project Description

### **CloudDocs — Full-Stack SaaS Cloud Storage Platform**
**Repository:** [github.com/Ayush-Mishra750/CloudDocs](https://github.com/Ayush-Mishra750/CloudDocs)  
**Tech Stack:** `React.js`, `Node.js`, `Express.js`, `MongoDB`, `Redis`, `AWS S3`, `CloudFront`, `Razorpay`, `Docker`

---

### 🚀 **Key Bullet Points (Concise & ATS-Optimized)**

* **Full-Stack SaaS Platform:** Built a secure cloud storage solution supporting multi-format file uploads, folder nesting, public link sharing, and real-time disk quota tracking.
* **Razorpay Billing & Subscriptions:** Implemented dynamic tier upgrades and automated storage quota enforcement using Razorpay payment gateway and verified webhooks.
* **RBAC & Admin Dashboard:** Designed Role-Based Access Control with an Admin Panel for user management, role toggling, quota adjustments, and file purge workflows.
* **AWS S3 & CloudFront Integration:** Integrated AWS S3 for secure file storage and CloudFront CDN for optimized content delivery and fast asset distribution.
* **Advanced Auth & Features:** Added Google Drive import, Google OAuth 2.0, Resend OTP email verification, Redis session caching, and Docker containerization.
